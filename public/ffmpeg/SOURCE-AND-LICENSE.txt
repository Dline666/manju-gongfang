FFmpeg WebAssembly distribution / source and license information

Scope
-----
This directory contains only the two runtime files required by the single-thread
ESM @ffmpeg/core 0.12.10, plus license, provenance and source-access notices.
No multi-thread core, ffmpeg-core.worker.js, sample video or CDN loader is shipped.
The application wrapper's module Worker is bundled by Vite from the installed
@ffmpeg/ffmpeg 0.12.15 package. It is NOT a second pthread/multi-thread core.

Obtaining source and build scripts
---------------------------------
The wrapper/core repository release tag is v12.15 (NOT v0.12.15).
Its packages/core/package.json declares 0.12.10 and packages/ffmpeg is 0.12.15.
Upstream snapshot:
https://github.com/ffmpegwasm/ffmpeg.wasm/tree/71aa99d37c02a7b4c435275ca9ef50e612f6efa1
Downloadable source:
https://github.com/ffmpegwasm/ffmpeg.wasm/archive/71aa99d37c02a7b4c435275ca9ef50e612f6efa1.tar.gz
Build recipe (a verbatim copy is upstream-build.txt):
https://github.com/ffmpegwasm/ffmpeg.wasm/blob/71aa99d37c02a7b4c435275ca9ef50e612f6efa1/Dockerfile
Also retain Makefile, build/*.sh, src/bind and src/fftools from that snapshot.
Upstream single-thread production build command: make prd
This invokes make build-st FFMPEG_ST=yes, using emscripten/emsdk:3.1.40,
-O3 -msimd128, disabled pthreads and WORKERFS. Requires Docker/buildx and the
full referenced dependency sources. No FFmpeg rebuild was performed here.
The FFmpeg source baseline in the Dockerfile is n5.1.4:
https://github.com/FFmpeg/FFmpeg/archive/refs/tags/n5.1.4.tar.gz

Runtime use
-----------
The application explicitly loads same-origin ffmpeg-core.js / ffmpeg-core.wasm.
Serve .wasm with application/wasm and permit same-origin module workers.
No crossOriginIsolated/SharedArrayBuffer requirement is imposed by this ST core.
The -msimd128 build requires a modern WebAssembly SIMD-capable browser.
All source videos and intermediates stay in memory. Exporting a user's encoded
MP4 is distinct from distributing the FFmpeg executable/core itself.
